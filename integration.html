1 Download or Link CSS & JS

Copy google-translate.css and google-translate.js from the vanilla/ folder into your website directory.

2 Drop into your HTML page
index.html 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <!-- 1. Link the CSS in <head> -->
  <link rel="stylesheet" href="./google-translate.css">
</head>
<body>

  <header>
    <!-- 2. Place this container element anywhere in your navbar -->
    <div id="google-translate-widget"></div>
  </header>

  <!-- 3. Include the Script at the bottom of <body> (Auto-initializes) -->
  <script src="./google-translate.js"></script>
</body>
</html>
